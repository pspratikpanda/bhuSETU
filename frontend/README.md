# Bhu Setu frontend

JavaScript/JSX React prototype built with Vite. Install with `npm install`, copy `.env.example` to `.env.local`, then run `npm run dev`. `npm run build` creates the static production bundle.

Pages use local fictional data through service modules; no live API, authentication, document storage, or AI service is included. See the root README and `../docs/` for integration plans. All components use `.jsx` and modules use `.js`.
