# AI service plan

No OCR, Gemini, model inference or AI API is connected. UI samples marked **AI Extracted Data — Prototype** are fictional.

Potential FastAPI services: OCR, document classification and extraction, anomaly detection, explainable risk indicators, land-use change signals and encroachment screening. Define input consent, data minimization, model versioning, evidence provenance, confidence calibration, retention and access controls before use. Provide human review and a correction path. Indicators should describe potential anomalies and never be presented as proof of fraud, title or legal status.
