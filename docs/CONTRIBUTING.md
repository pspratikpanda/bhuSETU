# Contributing

1. Create a focused `feature/<area>` branch from the team's agreed stable branch.
2. Keep React components in `.jsx` and JavaScript modules in `.js`; do not introduce TypeScript files or configuration.
3. Keep mock data in `frontend/src/data`, data access in `frontend/src/services`, and shared UI in `frontend/src/components`.
4. Label fictional records and prototype behaviors. Do not add real personal data, secrets or unsupported claims.
5. Document proposed API changes as `PROPOSED API` and coordinate contracts with the backend team.
6. Before sharing a frontend change, run `npm run build` from `frontend/` and include route or responsive screenshots when relevant.
