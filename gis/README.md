# GIS integration plan

Current map features are fictional GeoJSON polygons rendered with Leaflet. Boundaries are illustrative and are not surveyed or legally valid.

Future work may include PostGIS-backed parcel geometry, authoritative boundary provenance, land-use layers, role-authorized GeoJSON APIs, approved tile sources, flood-risk overlays, imagery comparison and reviewed encroachment indicators. See `../docs/GIS.md`.
